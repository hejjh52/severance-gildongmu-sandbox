02 · 직접 찍고 수정하기
도면 맞추기
기준 층은 옅게, 작업 층은 진하게 겹칩니다. 실제 같은 승강로에 해당하는 두 지점을 찍은 다음 자동 정렬하면 정확도가 높아집니다.

회전과 이동은 작업 층에만 적용됩니다.

작업 순서

① 같은 구역·두 층 선택
② 엘리베이터 ID를 동일하게 지정해서 각 층에 표시
③ 자동 정렬 후 오차 확인
④ 계단/에스컬레이터·복도·입구 표시

지도에서 실제 시설의 가운데를 클릭하면 점이 추가돼요. 같은 엘리베이터는 여러 층에서 동일한 ID로 표시하세요.
계단·에스컬레이터는 층별 출발·도착점이 달라도 됩니다.

현재 층 연결시설

동일 시설의 층간 오차

보행 가능한 복도 중심선을 따라 차례로 클릭해 점을 연결하세요. 마지막은 동선 완료 버튼 또는 더블클릭·Enter 키로 마칩니다. 작성 중에는 Esc로 취소할 수 있습니다.

현재 층 보행 동선

방 중심이 아니라 사람이 실제로 들어가는 문 위치를 클릭해 주세요. 나중에 보행 동선과 이 점을 연결해서 경로를 생성할 수 있어요.

현재 층 입구·장소

층별 도면 이미지

1~6층 도면은 자동으로 불러옵니다. 8~20층은 8F.png, 9F.png처럼 이름을 지정해 일괄 업로드할 수 있습니다. 업로드 도면은 이 브라우저에 저장됩니다.

작업 파일 관리

도면 정렬·시설·동선·입구 데이터는 이 브라우저에 자동 저장됩니다. 다른 컴퓨터에서 이어서 작업하려면 JSON 내보내기가 필요해요. 이미지 원본은 별도 보관하세요.
